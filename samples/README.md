# Azərbaycan dilində səs nümunələri

Mənbə: [LocalDoc Azerbaijani ASR Dataset](https://huggingface.co/datasets/LocalDoc/azerbaijani_asr), LocalDoc, 2025.
Lisenziya: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Bütün fayllar: WAV, 16 kHz, mono, 16-bit PCM. Mənbə transkriptləri və sətir nömrələri `sources.json` faylındadır.

- `01_clean.wav`: ilkin nitq nümunəsi; format standartlaşdırılıb.
- `02_noise.wav`: ayrıca nitq nümunəsinə 12 dB SNR səviyyəsində süni ağ küy əlavə edilib.
- `03_fast_speech.wav`: ayrıca nitq nümunəsi səs tonu saxlanılaraq 1,35 dəfə sürətləndirilib.
- `04_numbers_names.wav`: 1991-ci il, Hollandiya və Qvido Van Rossum adı.
- `05_technical.wav`: Python, integer və float terminləri.

Küylü və sürətli nümunələr təbii şəraitdə qeydə alınmış ayrıca kateqoriyalar deyil, test üçün dəyişdirilmiş internet yazılarıdır. Transkriptlər mənbədən götürülüb, əl ilə yoxlanılmayıb.
